# `starlight-group-pages`

[![Netlify Status](https://api.netlify.com/api/v1/badges/b1625295-60bb-4f98-b6a6-e53af403b4fc/deploy-status)](https://app.netlify.com/projects/starlight-group-pages/deploys)

Starlight plugin to give your sidebar groups their own pages.

## Documentation

Read the [Starlight Group Pages docs](https://starlight-group-pages.netlify.app).

## Package

If you are looking for the Starlight plugin package, you can find it in the [`packages/starlight-group-pages/`](https://github.com/trueberryless/starlight-group-pages/tree/main/packages/starlight-group-pages) directory.

## Project structure

This project uses pnpm workspaces to develop a single Starlight plugin from the `packages/starlight-group-pages/` directory. A Starlight documentation site is also available in the `docs/` directory that is also used for testing and demonstrating the Starlight plugin.
